## about

I build distributed backend systems where correctness and trust are the whole point. That means Secure SDLC tooling behind release pipelines that can't ship unsigned code, identity platforms that hold up at 100K+ users, and signing services that stay fast under load.

At DigiCert I develop a secure release manager, productised for premium enterprise customers — tooling that generates SBOMs, CBOMs and SLSA attestations end to end, SAST scanning and vulnerability detection with SARIF reports, VEX generation, and PQC, vulnerability management with policy-based decisions — all backed by in-house PKI and signed attestations. Before that, at Blackhawk Network, I built an enterprise IAM platform from scratch with OpenID Connect, passkeys, and fine-grained policy authorization. At Infosys I worked on tax-platform infrastructure serving 50M+ registered users.

I also build AI developer tooling — a project memory store pairing pgvector semantic search with Tree-sitter AST parsing for method-level code resolution, which cut token consumption on LLM workflows, and an agentic Jira-to-implementation pipeline where every generated change is gated by its test suite before review.
